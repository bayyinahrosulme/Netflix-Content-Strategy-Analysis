### Netflix Content Strategy Analysis (2014–2021)

Analysis of 8,800+ Netflix titles using SQL, Excel, and Tableau 
to understand how Netflix's content strategy evolved over time.

## Tools Used
- Excel & Power Query — Data cleaning and summary view
- PostgreSQL — Data analysis
- Tableau Public — Interactive dashboard
- GitHub — Version control

## Dashboard
https://public.tableau.com/views/NetflixContent_17744602666110/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

## Key Findings
- Movies dominate Netflix's catalog with a surge between 2017-2020
- USA leads content production followed by India and the UK
- Top genres are Dramas, Comedies and International Movies
- TV Show additions remained flat compared to Movies
- International content grew significantly between 2016-2021
